# 排障

按「症状 → 原因 → 处理」组织。前三条是**实测踩过的**坑，不是推测。

## 1. 调用一直不返回，240/300 秒后超时失败

**症状**：`npm start` 里任务卡在「已发送，等待网页开始输出」；中转站侧超时。
**原因**：那个**专用会话标签页被挂起了** —— 浏览器把它变成白屏（URL 和标题还正常，
但页面里没有消息列表、没有输入框），扩展把提示词送进去了，页面却永远不会产出输出。
最常见诱因是浏览器的**睡眠标签页 / 资源节省**把长时间在后台的标签页丢弃了；
也可能是渲染进程崩溃（表现一样）。

**处理**：
1. 找到标题像对话名的那张 DeepSeek 标签页（例如「用户要求说你好 - DeepSeek」），**刷新它**；
2. 关掉省电/睡眠标签页：
   - Edge：`edge://settings/system` → 关闭「使用睡眠标签页节省资源」；或把 `chat.deepseek.com` 加进「永不休眠」
   - Chrome：`chrome://settings/performance` → 记忆节能/关闭标签页休眠，或把站点加入例外
3. 反复出现的话，考虑给专用标签页固定一个独立窗口并保持前台。

> 说明：本仓库目前**没有**白屏自愈看门狗（计划中）。出现该故障需要人刷一下页面。

## 2. 提示「扩展未连接」

**检查顺序**：
1. 浏览器是否开着？扩展是否已加载？（`edge://extensions` / `chrome://extensions`）
2. 加载的是不是**本仓库 setup 生成的 `chrome/` 目录**？
   如果你加载的是 `vendor/dsh-web-bridge/extension`，它**没有** `local-config.json`，永远连不上。
3. 同一浏览器配置里是不是装了两份？只留一份，删掉重复的并「重新加载」。
4. `npm run doctor` 看扩展目录里的配对文件与本机密钥是否一致；不一致就重新 `npm run setup`，
   然后在扩展卡片上点「重新加载」。

## 3. 提示端口 3081 被占用

**原因**：本机只能跑一套桥接。常见冲突是这台机器同时装着 **DSH 的网页桥接插件**
（它也监听 3081）。

**处理**：二选一 —— 关掉其中一个。查占用者：

```powershell
# Windows
Get-NetTCPConnection -LocalPort 3081 -State Listen | Select-Object OwningProcess
```
```bash
# macOS / Linux
lsof -i :3081
```

## 4. 上游校验失败

**症状**：`npm run setup` 报「上游完整性校验失败」。
**原因**：下载到的内容与上游 `SOURCE.json` 里记录的 43 个文件哈希不一致（下载被中间层改写、
或上游 tag 被移动过）。

**处理**：
```bash
npm run setup -- --force     # 重新拉取
```
仍然失败就**不要继续用**——先到上游仓库核对 tag 与 `SOURCE.json`。

## 5. 中文/emoji 变成问号或乱码

**症状**：网页那边收到的提示词里汉字变成 `?`。
**原因**：HTTP 请求体被逐块解码，跨块的多字节字符被切坏（这是**实现方**的 bug，
本仓库在读取请求体时已按「先收集字节、再整体 UTF-8 解码」处理）。
如果你在自己写的适配器里遇到，检查是不是 `for await (chunk of req) { raw += chunk }` 这种写法。

## 6. 工具调用不返回 `tool_calls`

**可能原因**：
1. 上游没有把 `tools` 透传进 `body`（见 [relay-side.md](relay-side.md) 第 2 节）；
2. 工具的参数 schema 让 Ajv 编译失败 → 客户端会记录一条「已降级为纯文本」的警告，
   本次就只会得到文本回答。检查日志里的 `警告：`，并把 schema 改成标准 JSON Schema
   （避免外部 `$ref`、避免非对象根）。

## 7. 找不到 `npm` / 版本过低

需要 **Node.js 22+**。`node -v` 确认；`npm run doctor` 也会检查。

## 8. 想看桥接内部到底走到哪一步

本机桥接的审计事件由上游宿主写入；本 lite 包默认只打关键事件
（`queued` / `completed` / `failed`）。要更详细：

- 看 `npm start` 窗口里的 `阶段：…` 行（扩展上报的实时阶段）；
- 需要完整审计日志时，让宿主把事件追加到文件（上游插件的 `auditPath`；
  ⚠️ 上游 `setup` **不会**创建该目录，缺失时它的事件会被静默丢弃）。

## 9. 安全提醒

- `config.json` 里有本机配对密钥（43 字符），**不要提交、不要外传**；`vendor/` 与 `chrome/` 也都在 `.gitignore` 里。
- 浏览器里那个专用会话是桥接的工作台：**不要**手动输入或删消息。
- 内容会发往 DeepSeek，也会经过你自己的中转站。别在不宜外发的项目里用。
